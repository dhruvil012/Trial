# 🏗️ Civil Engineer Calculator

A clean, fast, and mobile-friendly calculator for civil engineers.  
Built with pure HTML/CSS/JS — no frameworks, no dependencies.

## Features

- **90° Angle Solver** — Enter any 2 sides, get the 3rd. Enter all 3 to verify.
- **Concrete Mix Design** — Select grade (M10 to M40), enter volume, get material quantities.
- **Volume & Weight Calculator** — L×B×H → CUM, CFT, weight in kg/ton, and cement bags.

## Deploy on GitHub Pages

1. Create a new repo on GitHub
2. Upload `index.html` (and optionally `README.md`)
3. Go to **Settings → Pages**
4. Select **Deploy from a branch → main → / (root)**
5. Your site will be live at `https://yourusername.github.io/repo-name/`

## Formulas Used

- **Pythagoras:** a² + b² = c²
- **Dry Volume:** Wet Volume × 1.54
- **Concrete Density:** 2400 kg/m³
- **Densities:** Cement 1440, Sand 1600, Aggregate 1500 kg/m³
